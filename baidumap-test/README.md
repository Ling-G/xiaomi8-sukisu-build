# 百度地图自动化测试

默认流程：

1. 清除百度地图（`com.baidu.BaiduMap`）**全部应用数据及缓存**。
2. 启动应用，点击“同意”；定位权限选择“仅在使用中允许”；隐私保护指引选择“暂不开启”。
3. 点击顶部搜索框，输入 **开锁** 并搜索。
4. 等待搜索列表加载完成，**只检查第一屏**。找到 **嘉悦开锁**（包含以此开头的完整店名）就点击；第一屏没有则打印 **`LOG 没有找到`** 并正常结束，不滚动、不翻页、不更换关键词。

同屏有多个不同匹配项时停止报错，不随意选择。打开目标店铺后即结束。

## 环境与运行

已在小米 8 / Android 10 / MIUI 12.5.2、百度地图 **22.1.0（1660）** 上验证。手机需保持解锁、原生竖屏 **1080×2248**，开启 USB 调试并授予 Root。电脑需 Python 3 和 ADB。此包中的驱动仅适用于内核 `4.9.186-perf-g10af704`。

解压完整程序包，Windows 双击 **`运行.cmd`**，或在目录内执行：

```sh
python baidumap_flow.py
```

默认执行会重新初始化百度地图，登录状态、收藏等本地数据、离线地图及缓存都会被清除；云端数据不会被此程序主动修改。程序不会在启动前另行弹出确认。

ADB 连接多台设备时指定序列号：

```sh
python baidumap_flow.py --serial YOUR_DEVICE_SERIAL
```

仅调试当前页面时，可显式使用 `--resume search`（当前在地图首页）或 `--resume results`（当前在开锁搜索结果第一屏），这两种模式不清数据。默认店名前缀为 `嘉悦开锁`，可用 `--target` 指定；无需重新编译。

## 文件与日志

| 文件 | 用途 |
| --- | --- |
| `baidumap_flow.py` | 电脑端流程程序，只有 Python 标准库依赖 |
| `vt_touch.ko` | v0.2 点击驱动；公开、可独立卸载的 `/dev/vt_touch` |
| `vt_touch_test` | 驱动点击客户端 |
| `map-ui-helper.jar` | 一次性读取界面和填写中文；不安装 APK、输入法或常驻服务 |
| `运行.cmd` | Windows 启动入口 |
| `FILES-SHA256.json` | 依赖文件校验清单 |
| `runs/日期时间/` | 每次运行的 `run.json`、页面 XML、第一屏截图及结果/失败截图 |

点击操作通过 `vt_touch.ko` 完成；中文填写使用标准无障碍文本动作。页面按真实文字及元素边界识别。程序不会调用辅助程序中的滚动动作。

驱动不存在时自动加载；已加载旧 v0.1 时正常卸载并更新到 v0.2。被占用时会停止，不强制卸载。程序不会配置开机加载。v0.2 修正了重复点击时 Android 触摸槽识别问题。

原版 VT 不参与本流程。界面改版、权限弹窗变化、网络故障、锁屏或设备旋转时，程序可能停止并保存日志；页面未加载完成时不会输出“没有找到”。不同位置和时间的搜索排序可能不同。
